# Employee Management System - No MongoDB

Technologies:
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

MongoDB is NOT required.

## Run

Open terminal in this project folder:

npm install

npm start

Then open:

http://localhost:3000

Employee data is stored permanently in:

data/employees.json

Features:
- Add employee
- View employees
- Search employees
- Edit employee
- Delete employee
- Total employees
- Department count
- Average salary
